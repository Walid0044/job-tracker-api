JOB TRACKER API
A java spring boot backend project, which is Job Tracker Api in which CRUD operations used.
Search, validation and global exception handler are professionally used.
Swagger , Postman, and database Postgresql were used properly.

TECH STACK
Java language
spring boot framework
postgresql database
swagger and openApi for api documentation
postman for testing api
build tool , maven

KEY FEATURES
Posting, getting, deleting, updating operations are performed
Searching by companyName or status
Validation to make sure no junk data goes to database
global exception messages 

API DOCUMENTATION
once the application is running u can check out by swagger at , http://localhost:8080/swagger-ui.html
